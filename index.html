About

A Quick Intro

I started my career in private-sector technical support; with Akgün Bilgisayar I was assigned on-site to a public health project at Çorum Chest Diseases Hospital, and today I continue at Etiya as Principal Specialist — System and Infrastructure Management.

I joined Etiya in 2021 as System Support Specialist; over time I was promoted to Senior Specialist (2023) and then Principal Specialist (2025). In my current role I'm responsible for keeping the user accounts, email systems and server infrastructure used by employees across Etiya's Turkish and international offices running without interruption. Together with my team we cover system security, user management, backups, disaster recovery and process automation.

My technical focus is Microsoft Entra ID (Azure AD), SCCM and VMware vSphere; alongside these I work on hybrid identity (on-prem Active Directory ↔ Entra ID) and process automation (n8n + Jira). With the "Architecting on AWS" certification I earned in 2025, I'm investing further in the cloud side. With the experience I've gained on the field I take a solution-oriented and adaptive approach, and as a professional who values teamwork I aim to create both technical and cultural value.

  • Brought 1500+ computers under one centralized management Security updates and application installs for every company computer are now deployed centrally via SCCM and ManageEngine. With this standardized setup, compliance rose to over 95%: every device is updated under the same policy at the same time.
  • Keeping the server infrastructure always on I configured the VMware and Hyper-V servers running internal applications so that a single host failure does not disrupt the service. As a result, employees barely notice outages during the day; we maintain over 99.9% availability on business-critical services.
  • Moved user-account and email management to a hybrid model I integrated on-prem Active Directory with cloud-side Microsoft 365 / Azure AD so they behave as a single identity infrastructure. An employee logs in with the same username from the office or from home, permissions are managed from one place, and when someone leaves all access is revoked in one move.
  • Brought security & compliance standards into daily operations I translated ISO 27001 and PCI-DSS requirements into daily operations: access rights are clearly defined per system, CrowdStrike and Trend Micro EDR are rolled out across employee devices, and suspicious events are automatically detected and routed to the team.
  • Unified cloud and on-prem networking I designed AWS Route 53 to work together with the internal DNS servers. A user connecting from one of our international offices is routed to the closest server, which means applications open faster and more reliably.
